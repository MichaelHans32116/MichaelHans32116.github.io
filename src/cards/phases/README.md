# Custom Phase / Tab Card Overrides

Drop custom Cardmaker images (`.png`, `.jpg`, `.jpeg`, `.webp`) here to override the automatic live tab preview screenshots inside the bottom `Choose your tab` Phase Card Tray:

- `draw.jpeg` — `DP · Draw Phase`
- `standby.jpeg` — `SP · Home`
- `main.jpeg` — `MP1 · Deck`
- `battle.jpeg` — `BP · Experience`
- `end.jpeg` — `EP · Contact`

Any missing filename automatically falls back to the real captured tab preview screenshot in `src/images/phase-previews/`.
