# Drop Your Yu-Gi-Oh Card Images Here

Save your downloaded images right in this folder (`src/cards/`):

1. **`card-back.png`** (or `.jpg` / `.webp`) — Your Yu-Gi-Oh card back design for the stacked deck.
2. **`hans-card.png`** — Your downloaded card from `cardmaker.net/yugioh/`.
3. *(Optional)* Project cards if you make more on `cardmaker.net` (`buildbid-card.png`, `gatepass-card.png`, `insectra-card.png`, `howconnect-card.png`).
