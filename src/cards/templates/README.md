# Blank Cardmaker Templates (`src/cards/templates/`)

Drop up to **3 blank frames** downloaded from https://www.cardmaker.net/yugioh/ (keep Name, Picture, and Effect blank!):

1. **`project-frame.png`** *(e.g. Link/Blue frame — used for Projects)*
2. **`achievement-frame.png`** *(e.g. Trap or Synchro frame — used for Achievements & Certifications)*
3. **`about-frame.png`** *(e.g. Spell/Green frame — used for Experience, Tech Stack & About Me)*

Any `.png`, `.jpg`, `.jpeg`, or `.webp` extension works automatically — Vite picks them up via `import.meta.glob` and composites your logos, screenshots, titles, and effects straight into the frame!
